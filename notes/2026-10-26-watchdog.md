### Root cause of the stale deploy (known since 2026-10-05, STILL NOT FIXED)
`scrape.yml` pushes with the default `GITHUB_TOKEN`. GitHub suppresses downstream workflow triggers
for `GITHUB_TOKEN` pushes, so `pages.yml`'s `on: push: branches: [main]` never fires for those commits.
Only `workflow_dispatch` / `repository_dispatch` always create runs from `GITHUB_TOKEN`
([GitHub docs](https://docs.github.com/en/actions/how-tos/write-workflows/choose-when-workflows-run/trigger-a-workflow)).

→ **Fix (A) is staged in `fix-pages-auto-deploy.patch`** (adds `actions: write` + a
`gh workflow run pages.yml --ref main` step to `scrape.yml`). It has never been applied to `main`.
